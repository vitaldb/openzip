# OpenZip — Privacy Policy

_Last updated: 2026-05-02_

OpenZip is a local file-extraction utility. **It does not collect, store, transmit,
or share any personal information.**

## What OpenZip does NOT do

- ❌ No internet connection of any kind. OpenZip never contacts a server.
- ❌ No analytics, telemetry, or usage tracking.
- ❌ No crash reporting (crashes stay on your machine).
- ❌ No advertisements.
- ❌ No third-party SDKs or services.
- ❌ No access to files other than the ZIP archive you explicitly chose to extract,
  and the output directory you chose to extract it to.

## What OpenZip does locally

- Reads the `.zip` file you select via the Explorer context menu or by passing it
  on the command line.
- Writes the extracted contents to the destination folder you chose.
- May create a diagnostic log file at `%LOCALAPPDATA%\OpenZip\` to help you
  triage problems. **This file is never transmitted off your device** and you can
  delete it at any time.

## Microsoft Store distribution

OpenZip is distributed via the Microsoft Store. The Store itself collects
download statistics and (if the user opts in) crash telemetry — those flows are
governed by Microsoft's privacy policy, not ours. OpenZip does not add to or
modify what the Store collects.

## Open source

OpenZip's source code is published at https://github.com/vitaldb/openzip under
the MIT License. You can verify the absence of network, analytics, or
data-collection code yourself.
